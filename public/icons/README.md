# PWA Icons Required

Please add the following icon files to this directory:

- `icon-192x192.png` - 192x192 pixels (for mobile devices)
- `icon-384x384.png` - 384x384 pixels (for tablets)
- `icon-512x512.png` - 512x512 pixels (for high-res displays and splash screens)

These icons should be:
- PNG format
- Transparent or with your app's theme color background
- Feature your app logo/branding
- Purpose: "any maskable" for the 192x192 icon (works as both regular and maskable icon)

You can use tools like:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator
- Or create them manually in design tools like Figma/Photoshop

Current theme color: #2563eb (blue-600)
Background color: #f8fafc (slate-50)
